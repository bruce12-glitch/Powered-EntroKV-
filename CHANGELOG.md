# Changelog

## 0.2.0 · 2026-10-29

Page EntroKV expands from single-observation exploration to complete local research projects.

- Bounded Qwen2 capture CLI, CPU/CUDA command builder, pinned requirements, environment
  provenance, and an explicitly labeled random-weight CPU capture example.
- Multi-layer bundles, layer × group heatmaps, policy overlays, token inspection, and cancellable workers.
- Two-configuration comparison using valid-token Jaccard and common head-mean attention mass; CSV export.
- Complete local projects in IndexedDB, reopened with recomputation; v0.1 snapshots preserved.
- Full manifests with SHA-256 input/configuration/result checksums, import verification, and recomputation.
- Python/JavaScript binary hash parity and tiny Qwen2 CPU capture integration checks.

Validation covers random-weight Qwen2 CPU capture versus full eager attention. Pretrained CUDA
capture, generation quality, actual KV eviction, physical GPU savings, and vLLM serving remain future work.
